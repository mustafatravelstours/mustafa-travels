MUSTAFA TRAVELS — UMRAH DETAIL PAGE UPGRADE

1. Prerequisite: The earlier UMRAH-BUILDER-SQL.sql must already have been run.
2. Run UMRAH-SHARING-SQL.sql in Supabase SQL Editor once.
3. Upload/replace these files in the GitHub repository ROOT:
   umrah-builder.html, umrah-public.js, umrah-detail.html, umrah-detail.js
   (Keep your current supabase-config.js and other website files unchanged.)
4. In Admin > Umrah Brochure Builder, save the package first. Then click Edit in saved entries, enter final Double/Triple/Quad/Quint adult rates plus child/infant rates and click Save Sharing Prices. Publish the package in the main builder form.
5. On umrah.html click View sharing prices & package details.
6. Important: If you have not uploaded umrah-public.js / umrah.html from the previous upgrade, upload umrah.html too.
7. Calculator uses adult per-person room sharing rate, separate child/infant per-person prices; adults + children count towards beds, infants do not. Room count is rounded up. This is an estimate only; unused beds may require a supplement. Confirm child ages, occupancy and hotel policies before booking.
8. PRIVATE visa, transport and hotel costs are NOT exposed through the public tables or detail page.
9. No live availability or automatic booking; WhatsApp enquiry only.
